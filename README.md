# ipo-schedule-feed

한국 공모주(IPO) 청약·상장 일정 공개 JSON 피드. 매일 GitHub Actions로 자동 갱신됩니다.

- 데이터: [ipo_data.json](./ipo_data.json)
- 원본: [피너츠](https://www.finuts.co.kr) 공개 페이지
- 공개 fetch용 raw URL: `https://raw.githubusercontent.com/ukj3br-sketch/ipo-schedule-feed/main/ipo_data.json`

`공모주_관리시트.html` 대시보드가 로컬 서버 없이 이 URL을 직접 호출해 최신 청약 일정을 가져옵니다.
